# A股短线监控

个人使用的网页看板与QQ邮箱提醒程序。Python 3.10+，仅使用标准库，不需要安装第三方依赖。不连接券商，不自动交易。

## 启动与填写授权码

1. 安装 Python 3.10 或更新版本（Windows安装时勾选“Add Python to PATH”）。
2. 在本仓库目录打开终端，运行 `python -m app.server`（部分系统用 `python3 -m app.server`）。Windows也可双击 `start.bat`。
3. 在**运行程序的这台电脑**的浏览器地址栏输入 `http://127.0.0.1:8080`。这是本机地址，不是已发布的网站，其他电脑不能直接访问。
4. 页面底部的“QQ邮箱设置”里填写发件QQ邮箱、收件邮箱和SMTP授权码，点击保存。
5. 点击“发送测试邮件”，确认收件箱实际收到后，再勾选“启用自动邮件提醒”。SMTP采用 `smtp.qq.com:465` 和验证证书的TLS加密连接。
6. 程序与电脑需要保持运行、联网。手机开启QQ邮箱通知。测试成功仅表示当次邮件发送和接收正常，不保证邮件实时送达。

SMTP授权码在QQ邮箱官网的账户设置中开启SMTP后生成，**不是QQ登录密码**。不要在聊天、代码、Git或公共HTTP网站中填写。程序保存在 `.data/mail.json`，文件权限为0600，不会通过API返回授权码。该文件不是加密保险箱：任何能访问本机账户的人可能读取，应保护电脑账户；Windows另需依赖账户文件权限。取消自动邮件不会删除已保存凭证，撤销可在QQ邮箱管理中完成。不要备份或分享 `.data` 目录。

## 当前功能

- 五个指数：上证、深证成指、创业板、沪深300、中证1000；指数各自成交额，不能相加成两市总额。
- 涨幅靠前30个行业板块、成交额、行情源估算净流入。
- 持仓增改；卖出后请更新数量和成本，数量0退出监控。初始导入33只股票，成本来自用户截图，代码按名称匹配，需要核对；截图未显示ETF代码，通信ETF富国1700份、成本1.7811需手动补充。已清仓的金安国纪、广合科技未导入。
- 默认可用现金50000元、目标5只持仓，仅用于展示和收盘报告，不推算具体买入/卖出股数。
- 放量金叉：昨日MA4≤MA8，今日MA4>MA8，收盘上涨，成交量≥前5日均量×1.3。日线前复权；盘中临时金叉独立预警，累计成交量与前5日**全天**均量比较，非同时间量比。盘中信号可能失效。
- 候选池是当前涨幅前100只，每轮最多轮换检查10只；排除ST/退市名称，至少20条日线。不是全市场扫描；频繁变动榜单可能遗漏股票。
- 持仓：日线趋势排序、死叉、放量下跌、成本亏损阈值和止盈观察阈值。默认亏损8%、止盈15%是可修改的观察条件，不是针对每只股票评估后的止损方案。
- 盘中持仓资金指标：两次新鲜报价（相隔不超过180秒）估算净流入变化≥1000万元时提醒；同股票同方向半小时去重。缺少报价时间戳、陈旧行情、接口失败时不触发。净流入是提供商估算，不等同真实新增资金。
- 15:05—15:10扫描取得当日完整数据时生成收盘持仓汇总。程序若没有在此窗口运行，不补发当日汇总。
- 邮件按扫描批次合并、按信号和日期去重，失败保留重试。SMTP未提供端到端幂等，极端断线时邮件可能重复。

## 限制与运行要求

免费东方财富HTTPS接口未承诺服务等级，可能限流、变动或延迟。看板记录获取时间，持仓行情另保存数据源时间戳；网页刷新不代表行情实时更新。没有有效数据时显示错误，不使用模拟行情替代。

后台按北京时间周一至周五9:30—11:30、13:00—15:10扫描，默认60秒**扫描完成后**等待；接口慢时实际周期更长。没有交易所节假日日历，节假日可能仍请求，但旧日线不发新的确认信号。手动“立即扫描”可用于排错和收盘核对。

尚未实现：两市成交额昨日同时刻对比、板块资金异动通知、板块与持仓归属匹配、量化回测、公告风险、券商可卖数量同步、基于风险预算的加减仓股数。排序只按日线趋势，不能据此自动选定最终5只。不同复权方式可能影响均线信号。

网络要求：HTTPS访问 `push2.eastmoney.com`、`push2his.eastmoney.com`，TCP/TLS访问 `smtp.qq.com:465`。代理仅支持HTTPS时，QQ SMTP可能不能连接，需要在允许SMTP出站的自己的电脑或服务器运行。DNS与防火墙也需允许。

默认监听本机。远程部署必须设置 `MONITOR_ACCESS_TOKEN`，使用HTTPS反向代理并限制访问，然后才可运行 `python -m app.server --host 0.0.0.0`。页面的远程访问口令为该变量值；授权码不能通过公网HTTP提交。当前项目没有已部署的公共页面。

## 开发与检查

```sh
python3 -m unittest discover -s tests -v
python3 -m app.server --port 8080
```

数据和邮件配置在忽略提交的 `.data/`；设置 `MONITOR_DATA_DIR` 可改目录。测试使用隔离临时目录和假行情，不读取个人授权码，也不发送真实邮件。测试验证策略与故障处理，不证明实时行情服务或实际邮件投递可用。`--no-worker` 可关闭后台扫描，便于接口测试。

各模块：`app/core.py` 持仓与信号计算，`app/market.py` 行情适配，`app/monitor.py` 轮询与提醒，`app/mail.py` SMTP，`app/server.py` Web服务，`app/index.html` 页面。
